## How to publish

- Each doc is a `.md` file with a short lowercase-hyphenated filename, e.g. `muse-scanning-loop.md`.
- Docs can sit at the root, or in topic folders once there are enough to group (e.g. `ai/`, `home/`). Folder names are lowercase-hyphenated too.
- Every new doc gets a row in the index above, linked by relative path, grouped under a topic heading once folders exist.
- Links between docs use relative `.md` paths so they work both on the site and in the repo.
- Commit and push. The site updates about a minute later.
- Start new docs from `_template.md` (files starting with `_` stay off the site).
